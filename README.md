# molten

A real-time ray-marched 3D lava lamp, rendered live in the browser with raw WebGL.
No model files, no textures, no libraries — the whole lamp is one fragment shader.

Live: https://joxan2137.github.io/

- Drag to orbit, tap the glass to nudge the wax
- Five mood presets, custom wax/liquid colours, four metal finishes
- Wax is a small heat simulation; the picture is a ray march through it
